# Classical Symmetric Ciphers

## Aim
To understand and implement Caesar and Vigenère ciphers for encryption and decryption.

## Description
This experiment demonstrates traditional symmetric key encryption techniques.

### Caesar Cipher
It shifts each letter by a fixed number of positions.

### Vigenère Cipher
It uses a keyword to shift letters for encryption and decryption.

## Operations
- Encryption
- Decryption

## Technology Used
- Python

## Result
Caesar and Vigenère ciphers were successfully implemented for encryption and decryption.

## Conclusion
The experiment helps to understand the basic working of classical symmetric key ciphers.
