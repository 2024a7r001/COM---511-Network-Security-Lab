# Experiment 3 – Secure Communication Protocols

## Aim
To capture and analyze secure communication protocols using Wireshark.

## Protocols Used
- TLS – Transport Layer Security
- SSH – Secure Shell
- WPA2 – Wi-Fi security protocol
- IPsec – Internet Protocol Security

## Tool Used
- Wireshark

## Method
1. Open Wireshark.
2. Select the network interface.
3. Start packet capture.
4. Generate secure network traffic.
5. Apply filters:
   - `tls`
   - `ssh`
   - `eapol`
   - `esp`
6. Analyze the captured packets.

## Example
When we open an HTTPS website, TLS creates a secure connection and encrypts the data.

## Result
The secure communication protocols were successfully captured and analyzed using Wireshark.

## Conclusion
Wireshark helps us understand how secure protocols protect network communication.
