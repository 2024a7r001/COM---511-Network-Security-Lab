# Experiment 8: Send and Receive PGP Encrypted Email Using Thunderbird

## Aim
To send and receive secure emails using PGP encryption and digital signatures in Thunderbird.

## Requirements
- Mozilla Thunderbird
- Email Account
- Internet Connection

## Procedure
1. Open Thunderbird and set up an email account.
2. Create a PGP public key and private key pair.
3. Share the public key with the receiver.
4. Import the receiver's public key.
5. Enable encryption and digital signature.
6. Send the encrypted email.
7. The receiver uses their private key to decrypt and read the email.

## Result
Successfully sent and received PGP-encrypted and digitally signed emails using Thunderbird.

## Conclusion
PGP encryption helps keep emails secure, private and authentic.


**5. What is a digital signature?**  
It verifies the sender and ensures the message is not modified.
